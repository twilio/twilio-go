**Type** | **string** | A URI reference (RFC3986) that identifies the problem type. This URI should resolve to human-readable documentation for the problem type. When dereferenced, it SHOULD provide human-readable documentation for the problem type (e.g., using HTML). For Twilio errors, this should be a URL to https://www.twilio.com/docs/api/errors/{code}  |
**Title** | **string** | A short, human-readable summary of the problem type. It SHOULD NOT change from occurrence to occurrence of the problem, except for purposes of localization.  |
**Status** | **int** | The HTTP status code generated by the origin server for this occurrence of the problem. This is the same as the HTTP status code returned in the response.  |
**Detail** | Pointer to **string** | A human-readable explanation specific to this occurrence of the problem. This field's value can change between different occurrences of the same problem type to provide specific details.  |
**Instance** | Pointer to **string** | A URI reference that identifies the specific occurrence of the problem. It may or may not yield further information if dereferenced. This can be used for correlation and debugging.  |
**Code** | **int** | Twilio-specific error code (extension member). This numeric code uniquely identifies the error type within Twilio's error taxonomy and can be used for programmatic handling. Registered at https://www.twilio.com/docs/api/errors  |
**Errors** | Pointer to [**[]InlineObjectErrors**](InlineObjectErrors.md) | Twilio-specific extension for validation errors (typically HTTP 400/422). Contains an array of individual field-level validation errors, each with a human-readable detail message and a JSON Pointer (RFC 6901) indicating the location of the error in the request. This is particularly useful for request validation failures where multiple fields may have errors.  |
